NSE V10 COMPLETE ALL-STOCK DASHBOARD

FEATURES
- One main button runs all-stock analysis and updates dashboard results.
- Attempts to load the current NSE equity universe from NSE archives and caches it locally.
- Top 15 opportunities.
- Search and analyse any NSE stock independently.
- Live NIFTY 50, BANK NIFTY and SENSEX.
- Sector-wise summary from scan results.
- Interactive TradingView chart for searched stocks.
- V10 targets, stop losses, risk, holding days, patterns, indicators and beginner reasons.
- Portfolio analysis and backtesting.
- Excel report.

RUN
py -m pip install -r requirements.txt
py -m streamlit run app.py --server.address 0.0.0.0

MOBILE
Use the computer IPv4 address and open http://YOUR_PC_IP:8501 on the same Wi-Fi.
The computer must remain on while the local dashboard is being used.
